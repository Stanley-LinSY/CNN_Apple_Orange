## Overview

This project trains a custom CNN to perform 3-class image classification:

| Class | Label |
|-------|-------|
| 🍎 Apple | `0` |
| 🍊 Orange | `1` |
| ❓ Unknown | `2` |

The pipeline covers the full ML workflow: data splitting → preprocessing → image sharpening → model training → evaluation → deployment via Streamlit and live webcam.

---

## Model Architecture

Built from scratch using TensorFlow/Keras Sequential API:

```
Input (224×224×3)
  │
  ├── Conv2D (32 filters, 3×3, ReLU) → MaxPool2D (2×2)
  ├── Conv2D (64 filters, 3×3, ReLU) → MaxPool2D (2×2)
  ├── Conv2D (128 filters, 3×3, ReLU) → MaxPool2D (2×2)
  ├── Conv2D (256 filters, 3×3, ReLU) → MaxPool2D (2×2)
  ├── BatchNormalization
  ├── Flatten
  ├── Dropout (0.6) → Dense (64, ReLU) + L2 regularization
  ├── Dropout (0.4) → Dense (32, ReLU) + L2 regularization
  └── Dropout (0.2) → Dense (3, Softmax) + L2 regularization
```

**Training config:**
- Optimiser: Adam (`lr = 1e-5`)
- Loss: Categorical Cross-Entropy
- Epochs: 10
- Batch size: 16
- Callbacks: ModelCheckpoint, EarlyStopping (`patience=40`)

## Dataset

- **4,345 images** total across 3 classes (Apple, Orange, Unknown)
- All images resized to **400×400** (stored in `DatasetV1`)
- Split into Train / Test / Validation using `sklearn.train_test_split`
  - Test: 5% · Validation: 5% · Train: remaining ~90%

| Split | Images |
|-------|--------|
| Train | 3,919 |
| Validation | 208 |
| Test | 218 |

**Preprocessing applied:**
- Pixel normalisation (0–255 → 0–1)
- Augmentation on training set: rotation (±20°), width/height shift (±20%), horizontal flip
- **Image sharpening** via a 3×3 sharpening kernel using OpenCV (`cv2.filter2D`), applied to all splits before training

## Usage

### 1. Train the Model (Jupyter Notebook)

Open and run `2120795_StanleyLin_Orange_2112422_WaiYanAung_Apple.ipynb` step by step:

1. **Data Splitting** — distributes `DatasetV1` into Train/Test/Valid → `DatasetV2`
2. **Image Preprocessing** — augmentation setup via `ImageDataGenerator`
3. **Image Sharpening** — applies sharpening kernel to all splits → `DatasetV3`
4. **Model Building & Training** — defines and trains the CNN
5. **Matplotlib Visualisation** — plots accuracy and loss curves
6. **Live Detection** — streams from a webcam via DroidCam (`cv2.VideoCapture`)
7. **Model Summary** — prints full layer summary
8. **Evaluation** — evaluates on test set

### 2. Streamlit Web App

```bash
streamlit run oau_app.py
```

Upload a `.jpg` or `.png` image and the app will predict:
- 🍎 **It is an Apple!**
- 🍊 **It is an Orange!**
- ❓ **It is unknown!**

Along with the raw probability scores for all 3 classes.

### 3. Live Webcam Detection

The notebook's live detection cell uses **DroidCam** (phone-as-webcam via IP stream). Update the URL in the notebook to match your device's IP:

```python
w = 'http://<your-device-ip>:4747/video'
```

Press `q` to quit the OpenCV window.
